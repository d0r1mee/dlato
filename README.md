# Другие цвета

3D-игра от первого лица о бытовых трудностях людей с нарушениями цветовосприятия.
Весь цвет в игре существует только в 3D-сцене и проходит через «глаз» героя — пост-обработку камеры.
Интерфейс намеренно монохромный, чтобы не выдавать цвета мимо фильтра.

## Эпизод 1. Колбочки

Семилетний Миша приходит в поликлинику: родители заметили, что он раскрасил небо зелёным, а солнце розовым.
В холле он знакомится с Аней, у которой ахроматопсия, и узнаёт, что такое дальтонизм (можно посмотреть её глазами).
У офтальмолога Миша проходит тест цветными таблицами, узнаёт о своей тританопии, изучает плакаты про колбочки
и решает головоломку на «колбочкометре». После титров открывается свободный режим с переключением всех пресетов.

## Запуск

Нужен любой статический сервер (ES-модули не грузятся с `file://`). Three.js подключается с CDN.

```
powershell -ExecutionPolicy Bypass -File serve.ps1
```

Затем открыть http://localhost:8080. Подойдёт и `npx serve`, `python -m http.server` или Live Server в VS Code.

Управление: WASD — ходить, мышь — смотреть, E — взаимодействовать, ЛКМ/Пробел — дальше по диалогу,
1–4 — варианты ответа, Esc — пауза. В свободном режиме 1–8 переключают восприятие.

### Отладочные параметры URL

- `?dev` — клавиши 1–8 работают всегда, объект `window.game` в консоли
- `?autostart&skip=office` — сразу у двери кабинета
- `?autostart&sim` — сразу свободный режим
- `?dev&autostart&pose=x,z,yaw,pitch&vis=tritanopia&plate=5` — поза камеры, пресет, таблица на мольберте

## Модель зрения

- Протанопия, дейтеранопия, тританопия: метод Brettel, Viénot & Mollon (1997) в линейном sRGB,
  коэффициенты из [libDaltonLens](https://github.com/DaltonLens/libDaltonLens).
- Протаномалия, дейтераномалия, тританомалия: интерполяция между нормой и дихромазией (сила 0.6), это приближение.
- Ахроматопсия: только яркость, плюс размытие (низкая острота зрения), ореолы и пересвет (светобоязнь).

Таблицы и «неправильный» рисунок генерируются процедурно: цифра и фон отличаются только сдвигом вдоль оси смешения
(ядра матрицы симуляции), поэтому при тританопии цифра исчезает полностью, а при нормальном зрении видна.

## Структура

| Файл | Что внутри |
|---|---|
| `src/main.js` | рендерер, игровой цикл, режимы, взаимодействие, экраны |
| `src/vision.js` | пресеты восприятия и математика симуляции |
| `src/postfx.js` | пост-обработка (шейдер «глаза») и плавные переходы между пресетами |
| `src/player.js` | контроллер от первого лица, столкновения, повороты камеры в сценах |
| `src/world.js`, `hall.js`, `office.js` | геометрия уровня |
| `src/characters.js` | персонажи из примитивов |
| `src/ishihara.js` | генератор псевдоизохроматических таблиц |
| `src/puzzle.js` | головоломка «Колбочкометр» |
| `src/story.js`, `story_office.js` | сценарий эпизода |
| `src/ui.js`, `audio.js`, `textures.js`, `posters.js` | диалоги и HUD, синтезированный звук, процедурные текстуры |
